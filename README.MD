# GuessNumberGameConsole (DevOps version)

Консольная версия игры «Угадай число» для демонстрации контейнеризации Java‑приложения в Docker.

Этот проект показывает, как упаковать интерактивное консольное Java‑приложение в контейнер и запустить его с правильными флагами для работы с вводом пользователя.

## Особенности
- Полностью консольный интерфейс: реализован через Scanner и System.out без графических компонентов.
- Валидация ввода имени: проверка на пустое значение, запрет на ввод только цифр, автоматическое приведение первой буквы к заглавной.
- Валидация ввода чисел: контроль диапазона, обработка ошибок и некорректного ввода без падения приложения.
- Псевдографика для заголовков и поздравлений, улучшает читаемость в терминале.
- Совместимость с Java 8: компиляция с флагами -source 1.8 -target 1.8 для максимальной переносимости.
- Docker‑ready: проект подготовлен для сборки в образ и запуска в контейнере с учётом интерактивной природы приложения.

## Локальный запуск
1.  Убедитесь, что установлен JDK 8 или выше.
2.  Скомпилируйте проект:
    ```bash
    javac -source 1.8 -target 1.8 -d . src/GuessNumberGameConsole.java
    ```
3.  Запустите игру:
    ```bash
    java GuessNumberGameConsole
    ```

### Сборка и запуск в Docker

1.  В папке с проектом (где лежат Dockerfile и скомпилированный GuessNumberGameConsole.class) соберите образ:
    ```bash
    docker build -t guess-number-console:v1 .
    ```
2.  Запустите контейнер в интерактивном режиме:
    ```bash
    docker run -it --rm guess-number-console:v1
    ```
    Флаги подобраны специально под тип приложения:
    * -i подключает стандартный ввод (stdin), чтобы игра могла считывать ввод пользователя.
    * -t выделяет псевдо‑TTY, чтобы корректно отображались строки и курсоры в терминале.
    * --rm автоматически удаляет контейнер после завершения игры.
